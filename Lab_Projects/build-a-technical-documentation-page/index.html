Introduction

HTML (HyperText Markup Language) is the standard language for creating web pages.

It structures the content on the web and tells the browser how to display text, images, links, and more.

<!DOCTYPE html>

The above declaration defines the document as HTML5.

  • Easy to learn
  • Widely used
  • Supported by all browsers
HTML Elements

HTML documents are made up of elements. These elements define the structure and content.

An element is defined by a start tag, some content, and an end tag.

<p>This is a paragraph</p>

Some elements are self-closing like <img>.

  • Block elements
  • Inline elements
Attributes

HTML elements can have attributes that provide additional information.

Attributes are placed in the start tag and usually come in name/value pairs.

<a href="https://example.com">Link</a>

The href attribute specifies the URL for the link.

  • href
  • src
  • alt
Text Formatting

HTML provides many tags for formatting text.

These include bold, italic, underline, and more.

<strong>Bold text</strong> <em>Italic text</em>

These tags help emphasize and structure text meaningfully.

  • <b>
  • <u>
  • <mark>
Forms and Inputs

Forms are used to collect user input.

The <form> element wraps input fields and submit buttons.

<input type="text" name="username"> <input type="submit" value="Send">

Inputs can be of many types like text, password, email, etc.

  • Text input
  • Password input
  • Submit button
